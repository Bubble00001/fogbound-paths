### 描述

地图改为可横向行走甚至向下走（只要没被走过），并且为地图引入战争迷雾与侵蚀机制，迷雾和侵蚀可配置，侵蚀边界随步数推进，被侵蚀的区域怪物会获得加强，当前仅支持正式版本103.2。

### 安装说明

1. 将 FogboundPaths 文件夹放入 Slay the Spire 2/mods/ 目录。

2. 确保已安装前置模组 STS2-RitsuLib 。

3. 启动游戏，在 Mod 设置中可修改相关配置。

### 主要特性

- 全向探索 — 同行节点可左右双向行走，纵向路径可逆向返回（仅限未走过的节点，走过即不可回退）。

- 战争迷雾 — 未揭示的节点显示为灰暗问号，仅当前位置周围几步的节点可见。

- 侵蚀退却 — 每走一步侵蚀边界向 Boss 方向推进，被侵蚀的怪物获得额外力量、覆甲。

- 宝箱行重塑 — 宝箱行保留最左和最右两个宝箱，中间节点随机为怪物、精英或问号。

- 可配置项 — 迷雾开关、侵蚀缓冲步数（0-20）、视野深度（0-20）。

### 前置要求

- STS2-RitsuLib （必须）

- 《杀戮尖塔 2》103.2版本

### Description
Makes the map traversable sideways and even backward (unvisited tiles only), and introduces configurable fog-of-war with an advancing erosion boundary. Eroded enemies gain bonus strength and plating. Currently supports stable version 0.103.2 only.

### Installation
1. Place the FogboundPaths folder into your Slay the Spire 2/mods/ directory.
2. Ensure the prerequisite mod STS2-RitsuLib is installed.
3. Launch the game. Related settings can be adjusted in Mod Settings.
### Main Features
- Free traversal — Move left and right within the same row, and backtrack along vertical paths, as long as the tile hasn't been visited yet.
- Fog of war — Unrevealed nodes appear as darkened question marks. Only nodes within a few steps of your current position are visible.
- Erosion — The erosion boundary advances toward the Boss with every step. Eroded enemies gain bonus Strength and Plating.
- Treasure row rework — Only the leftmost and rightmost nodes in the treasure row remain as Treasures; middle nodes are randomized into Monsters, Elites, or Unknowns.
- Configurable — Fog toggle, erosion buffer (0–20), reveal depth (0–20).
### Requirements
- STS2-RitsuLib (required)
- Slay the Spire 2 version 0.103.2
